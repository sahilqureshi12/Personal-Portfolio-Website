# Personal Portfolio Website

This is a personal portfolio website created using **HTML**, **CSS**, and **JavaScript**. It showcases your skills, services, projects, and contact information. It also includes a working contact form integrated with Google Sheets.

## ⚙️ Setup Instructions

To set up and run this project locally:

1. **Clone the repository** or download the source files:
   ```bash
   git clone https://github.com/sahilqureshi12/Personal-Portfolio-Website.git
   cd portfolio-website
   ```

2. Open index.html in a web browser:

You can simply double-click the index.html file or open it via a local development server such as
```bash
npx live-server
```

📌 Dependencies
This project uses:

Font Awesome — for icons.
```bash
<script src="https://kit.fontawesome.com/f47cc2b846.js" crossorigin="anonymous"></script>
```
Google Apps Script (for contact form submissions):

A Google Apps Script web app is used to receive form submissions and store them in a Google Sheet.

Replace the scriptURL value in index.html with your own deployed Apps Script endpoint.
